# DevArt-Pringels - Landing Page 🥔

Projeto de landing page interativa da marca de batata chips **Pringles**, com foco em **apresentação dos seus mais famosos sabores**, **animações com slider e interações com scroll** , responsivo no desktop e mobile.

O objetivo principal do projeto é explorar animações avançadas com **JS e Three.js**, **SplitText (GSAP)** e **Clip-Path (CSS)**, mantendo uma estrutura de código organizada, performática e escalável.

---

## 🎯 Objetivo do Projeto

- Criar uma experiência visual imersiva nos sabores das batatas
- Trabalhar animações sincronizadas com o scroll
- Explorar efeitos de texto com **SplitText**
- Aplicar boas práticas de animação e performance com JS e Three.js

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Three.js**
- **GSAP (GreenSock Animation Platform)**
  - SplitText

---

## ✨ Principais Funcionalidades

- 🎬 **Animações com texto (SplitText)** com GSAP
- 🧠 **Animações com slider**
- 🩸 **Efeitos na passagem dos slides** (clip-path)
- 🖥️ **Layout responsivo** para desktop e mobile
- 🎨 Identidade visual inspirada no site oficial da Pringles
